# Muse Gadget 硬件（ESP32-C5）

## 板子

- ESP32-C5 DevKitC-1，用户 2026-11-17 决定买板子自己做 Muse Gadget 硬件。
- 板子还没到手就先别刷机，等用户说板子到了再动手。

## 流程

- 用 Meta 开源的 Muse Gadgets 固件刷板子。
- 刷好后拿 token，在设备页面打开 community-device 设置完成配对。
- 板子到了之后的顺序：刷固件 → 拿 token → 配对，全程 Juno 帮他做。

## 注意

- 这是用户自己动手的硬件项目，不要替他下单买板子，只在他说板子到了之后接手刷机和配对。
